# 🌙 Little Muslim Companion

*A fun Islamic learning app for children to learn stories, duas, and quizzes interactively!*

---

## 📖 About the Project

**Little Muslim Companion** is an educational Islamic app designed for children aged **5–12 years**.

The app makes Islamic learning simple, interactive, and enjoyable through:

- Authentic Islamic stories  
- Daily duas  
- Interactive quizzes  
- Progress tracking  
- Audio storytelling  

This project combines **AI + Islamic education + gamification** to create a meaningful learning experience.

## ✨ Features

### 📚 Storytime
Generate Islamic stories for children based on authentic sources.

- Uses Qur’an & Sahih Hadith  
- Includes references  
- Child-friendly storytelling  
- Audio narration available  

---

### 🙏 Daily Duas
Learn important daily duas.

- Arabic text  
- English translation  
- Random dua generation  
- Learning history tracking  

---

### 🎮 Islamic Quiz
Test knowledge through quizzes.

- AI-generated questions  
- Multiple-choice format  
- Instant answer checking  
- Reward points system  

---

### ⭐ Progress Tracker
Track learning journey.

- Points earned  
- Duas learned  
- Stories listened  
- Quizzes attempted  

---

## ⚙ Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/Little-Muslim-Companion.git
cd Little-Muslim-Companion
```

---

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 API Setup

Create environment variable:

```bash
MY_API_KEY=your_api_key_here
```

For Hugging Face Spaces:

Go to:

**Settings → Secrets → Add Secret**

Add:

```bash
MY_API_KEY
```

---

## ▶ How to Run

Run the app:

```bash
python app.py
```

Gradio will generate a local URL.

## 🎯 How It Works

### Story Generator
AI creates Islamic stories using authentic sources.

Sources include:

- Qur’an  
- Sahih Bukhari  
- Sahih Muslim  
- Abu Dawood  
- Tirmidhi  
- Nasa’i  
- Ibn Majah  
- Tafsir Ibn Kathir  

---

### Dua Generator
Provides daily duas randomly from a pre-defined collection.

---

### Quiz Generator
Creates interactive Islamic quiz questions.

---

### Progress System
Stores progress in:

```bash
progress.json
```
